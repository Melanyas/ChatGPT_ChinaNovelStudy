# 市场机会雷达模板（题材 / 人设 / 冲突 / 节奏 / 商业潜力）

## 1. 评分结构（100 分）

- 题材机会（20）
- 人设辨识度（20）
- 冲突引擎（20）
- 节奏与钩子（20）
- 商业潜力（20）

## 2. 维度定义

### 题材机会（20）
- 是否处于上升赛道（近 4 周热度）
- 是否具备差异化子设定

### 人设辨识度（20）
- 主角核心欲望是否明确
- 配角是否有功能分工与记忆点

### 冲突引擎（20）
- 外部冲突（敌对势力）是否持续升级
- 内部冲突（价值/关系/自我）是否存在

### 节奏与钩子（20）
- 每章是否有信息增量
- 章末钩子强度（疑问/危机/反转/揭示）

### 商业潜力（20）
- 长线连载可持续性
- 改编潜力（影视/动漫/短剧/游戏）
