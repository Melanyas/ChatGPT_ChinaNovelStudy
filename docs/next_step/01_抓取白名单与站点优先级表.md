# 抓取白名单与站点优先级表（合规版）

> 目标：只做公开可访问、可合规采集的数据，用于趋势研究与文本特征分析，不做侵权复用。

## A. 白名单准入规则（必须全部满足）

1. 页面无需登录即可访问。
2. robots.txt 未禁止目标路径抓取。
3. 平台条款未明确禁止该类自动访问（如仅允许人工浏览则排除）。
4. 仅抓取元数据与必要片段，不抓完整受版权保护正文用于再分发。
5. 对用户评论做脱敏处理（ID哈希、去个人信息）。

## B. 站点类型优先级（先类型后具体站点）

### P0（最高优先）
- 公开榜单页（分类榜、热销榜、新书榜、完本榜）
- 公开书籍元数据页（题材、字数、更新状态、标签）

用途：
- 题材热度趋势
- 更新频率与市场反馈关系
- 标签组合与排名相关性

### P1
- 公开评论区/讨论区（限公开）
- 公开活动页（征文、题材扶持）

用途：
- 用户情绪聚类
- 弃读信号识别（“注水”“降智”“节奏慢”）

### P2
- 社交平台二次讨论（话题、短评、书单）

用途：
- 外溢声量
- IP化潜力早期信号

## C. 抓取频率建议（降低风险）

- 榜单页：每 6~12 小时一次
- 详情元数据页：每日一次
- 评论/讨论页：每日一次或更低
- 失败重试：指数退避（1m/5m/15m）
- 全局并发：低并发（按域名限速）

## D. 字段设计（建议最小集合）

### book_snapshot
- source
- book_id
- title
- author
- category
- tags
- word_count
- update_status
- rank_type
- rank_position
- snapshot_time

### review_snapshot
- source
- book_id
- review_id_hash
- review_text
- sentiment_score
- keyword_flags（注水/节奏慢/降智等）
- snapshot_time

## E. 抓取任务优先顺序（14 天）

- D1-D3：仅接入 P0 榜单 + 元数据
- D4-D7：加入 P1 评论，先做情绪粗分类
- D8-D14：加入 P2 外部讨论，建立跨平台热度映射

## F. 风险清单

- 版权风险：不得存储并再发布长段正文
- 合规风险：不绕过反爬、不撞库、不提权
- 隐私风险：评论数据必须去标识化
- 解释风险：情绪模型结论需标注置信度
