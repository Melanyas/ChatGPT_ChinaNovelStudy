# 网文商品化方法论与自动化闭环（项目规整版）

## 1. 项目总目标

将“市场洞察 → 欲望发现 → 类型选择 → 文本生成 → 自动审阅 → 迭代优化”整合为可执行流程，持续输出更符合市场需求的网文商品。

## 2. 六层方法论框架

### A. 市场洞察层
- 采集评论与公开反馈；
- 统计情绪走势与负向高频词；
- 提取赛道痛点（如注水、降智、节奏慢、套路化）。

### B. 欲望发现层
- 把“负向反馈”翻译成“未满足欲望”；
- 示例：
  - “注水”→“高密度有效剧情欲望”；
  - “降智”→“高智商博弈欲望”；
  - “慢”→“短周期兑现欲望”。

### C. 选题与赛道层
- 使用雷达评分挑选赛道与项目优先级；
- 输出“重点开发 / 试投放打磨 / 暂缓立项”。

### D. 生成与写法层
- 以“未满足欲望 + 赛道”作为生成输入；
- 强化三类写法：
  1) 精巧对白（信息增量、角色张力）；
  2) 口语化表达（读感与代入）；
  3) 场景反应（角色行为与生理/动作反馈）；
- 在熟悉模板上做“再创造”而非机械复写。

### E. 自审阅层
- 自动审阅维度：语法、情绪、动作、对白、口语化、反应、技法再创造；
- 阈值闸门：章节总体分、钩子强度、项目分、负向词比例。

### F. 迭代优化层
- 循环运行（限时/限次）；
- 自更新词典（生成副本，人工审核后再吸收）；
- 每周复盘：保留有效写法，淘汰低转化模板。

## 3. 输出物标准

每轮至少产出：
- 市场洞察：`review_signals_*.json`
- 赛道评分：`radar_scores_*.csv`
- 文本样稿：`generated_novel_*.md`
- 自审阅：`chapter_audit_*.json`
- 审查闸门：`audit_*.json`（可选）
- 汇总：`summary_*.md`

## 4. 执行原则

1. 先市场后写作，不反过来；
2. 先欲望后情节，不空转设定；
3. 先审阅后发布，避免无效生产；
4. 先小步快跑，再扩张规模。
